# Active Bible Prompt Pack (41-60)

This pack captures the refined 90-120s animation prompts for the Kids Battle beta.

## Global Style Targets

- Reverent yet engaging; hopeful faith-forward tone.
- Pixar-style 3D cartoon feel with expressive eyes and clean silhouettes.
- Soft dramatic lighting (fire glow, storm moonlight, dawn/sunrise).
- Scene-by-scene flow for 1.5-2 minute autoplay cards.
- No modern overlays, no logos, no voice required in render prompt.
- Subtle KJV verse flash at key moment.
