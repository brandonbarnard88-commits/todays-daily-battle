    Supabase Checklist
    
          
    
            
    messages.hidden (boolean)
    Used for message moderation hide/unhide.
    
            
    messages.display_name (text)
    Stores display names for posts.
    
            
    message_reports table
    Stores user reports for moderation review.
    
            
    saved_collections table
    Stores saved verse collections per user.
    
            
    saved_verse_collections table
    Stores saved verses per collection.
    
            
    newsletter_signups table
    Enables export from Supabase (not just local).
    
            
    supporter_waitlist table
    Stores supporter waitlist emails.
    
            
    newsletter_signups.daily_opt_in / weekly_opt_in
    Stores reminder preferences.
    
            
    daily_battles table
    Run SQL from supabase-daily-battles.sql for daily featured content.
