# Scope freeze & founder capacity (seasonal)

**Purpose:** Protect the soul of todaysdailybattle.com *and* the single human carrying it.  
Derived from the friend evaluation (2026-08): authenticity and depth are strong; the structural risk is **solo sustainability** under chronic limits.

**Companion:** [NORTH-STAR-PRINCIPLES.md](./NORTH-STAR-PRINCIPLES.md), [STANDARD-OF-EXCELLENCE.md](./STANDARD-OF-EXCELLENCE.md).

---

## Operating rule (this season)

> **Do not add new campus wings until the front door is as merciful as the content.**

“Campus wings” = new languages, new product lines, new major hubs, large story batches, or parallel taxonomies that force another choice before rest.

---

## Prefer (in order)

1. **Front-door friction** — capacity chooser, progressive disclosure, one primary low-capacity path  
2. **Feeling-first finder** — `/find-a-path.html` routes to *existing* plans/Calm/Ask (no new library)  
3. **Reuse** — smoke tests, build scripts, curated packs, Remember game data  
4. **Depth polish** — fewer rooms, better prayer/step/return-to-quiet on what already ships  
5. **Rest** — shipped is enough; silence is valid ministry  

## Deprioritize (unless crisis)

- New multilingual pilots  
- New “University of X” tracks  
- New shop products that need fulfillment load  
- Feature parity with big Bible apps  
- AI chat as product surface  

---

## Decision filter for every PR

| Question | Fail → don’t ship as “expansion” |
|----------|----------------------------------|
| Does this help a **heavy** user rest sooner? | If only helps power users map more, disclose it |
| Does this **add** a new primary door on Home? | Prefer secondary / details |
| Can Brandon **maintain** this for a year without heroic weeks? | If no, cut scope |
| Does it protect **local-first / KJV / no pressure**? | Non-negotiable |

---

## Front door contract

When capacity is low, Home should offer at most:

1. **Too much** → Calm (or Heavy now)  
2. **One verse** → today’s verse  
3. **A little more room** → Ask the Word + Find a path  

Everything else (Plans full library, Kids, Family, Explore map, grow path, seasonal) stays **reachable but not simultaneous**.

---

## Support path (honest)

Optional giving and printables fund infrastructure and free outreach. Do not grow the shop until the front door and founder capacity are stable. Transparency page remains the source of truth: `where-support-goes.html`.
