Weekly 10-minute checklist

  1. Open GA4 → Realtime.
  2. Visit the live site, accept analytics cookies, view the verse, open BBE, focus Ask, search once, click Plans.
  3. Confirm events: home_verse_view, home_ask_search, search_query.
  4. Pages and screens (7/28 days): home, plans, calm, kids, explore.
  5. Events: funnel names below.
  6. Explore: event param topic on search_query / quick_search.

Cloudflare Web Analytics

  1. Cloudflare → Web Analytics → add site → copy beacon token.
  2. Cloudflare Pages → Settings → Environment variables → CF_ANALYTICS_TOKEN = that token.
  3. Redeploy. Beacon loads from script.js when set.
  4. View page views / top paths in Cloudflare (no Google cookies).
