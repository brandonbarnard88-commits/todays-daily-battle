Security & Privacy Basics

We use Cloudflare for HTTPS encryption (99%+ traffic), DDoS protection, and auto-updates. No personal data collected unless you sign in—then it's encrypted via Supabase (in transit & at rest). Sign-in optional. Everything works offline without an account.

XSS & Script Protection

We enforce a Content-Security-Policy (CSP) and Trusted Types so scripts and user content can't inject malicious code. User input is sanitized with DOMPurify before display. All inline scripts use nonces. No raw HTML from users or APIs reaches the DOM.
